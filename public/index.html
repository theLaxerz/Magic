🌟 Key Security Features

Authentication & Authorization

  • JWT-based authentication
  • Bcrypt password hashing
  • Role-based access control
  • Strong password requirements

Input Validation

  • XSS protection
  • NoSQL injection prevention
  • Parameter pollution prevention
  • Request size limits

API Security

  • Rate limiting (endpoint-specific)
  • CORS configuration
  • Comprehensive error handling
  • Request validation

Security Headers

  • Content Security Policy
  • HSTS with preload
  • X-Frame-Options: DENY
  • Referrer-Policy: no-referrer

Database Security

  • Secure MongoDB connections
  • Parameterized queries
  • TLS/SSL in production
  • Connection pooling

AI/MCP Security 🤖

  • Prompt injection prevention
  • Input validation for AI
  • Content filtering
  • Audit logging

📚 API Endpoints

Authentication

POST /api/auth/register

Register a new user with strong password requirements

POST /api/auth/login

Login and receive JWT token (Rate limit: 5/15min)

GET /api/auth/me

Get current user profile (requires authentication)

Posts

GET /api/posts

Get all posts with pagination

POST /api/posts

Create a new post (requires authentication)

POST /api/posts/:id/comments

Add comment to a post (requires authentication)

AI/MCP

POST /api/ai/prompt

Submit AI prompt with security validation (Rate limit: 10/min)

POST /api/ai/mcp/execute

Execute MCP tool with security measures

GET /api/ai/usage

Get AI usage statistics

🚀 Quick Start

# Install dependencies
npm install

# Configure environment
cp .env.example .env

# Start MongoDB
docker run -d -p 27017:27017 mongo:latest

# Run the application
npm run dev

# Server runs on http://localhost:3000
